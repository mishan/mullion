        Keys and gestures
        Drag a tabonto a tab strip to put it there, a pane to stack, an edge to split, the drawer to close
        Esc while draggingtake the drag back
        Drag a divideror focus it and use the arrows; double-click evens it up
        Alt ←↑→↓focus the pane that way
        Alt Shift ←↑→↓move the pane that way
        Alt \ / Alt -split right / split down
        Alt Enterzoom the pane in front
        Alt Wclose it: to the drawer, or for a file you added, closed
        Alt 0start this layout over
        Ctrl Enterrun the preview

        The Alt chords do nothing while you are typing in an editor, so they never take a character from you. Press Esc and then Tab to leave an editor by keyboard.
